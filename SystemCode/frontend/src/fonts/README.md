# Self-hosted fonts

The app runs offline, so its two fonts are bundled here instead of loaded from Google Fonts.

| File | Font | Source | Licence |
| --- | --- | --- | --- |
| `Outfit-latin-variable.woff2` | Outfit (variable, weights 100–900; the app uses 300–600) | Google Fonts (latin subset), from https://github.com/Outfitio/Outfit-Fonts | SIL Open Font License 1.1, `OFL-Outfit.txt` |
| `GeistMono-latin-variable.woff2` | Geist Mono (variable; the app uses 400–500) | Google Fonts (latin subset), from https://github.com/vercel/geist-font | SIL Open Font License 1.1, `OFL-GeistMono.txt` |

The OFL permits bundling and redistributing the fonts with software, provided the licence text travels with them and
the fonts are not sold on their own. Characters outside the latin subset (for example ≤, ≥) fall back to system fonts.
