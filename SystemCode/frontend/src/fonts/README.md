# Fonts

Switzer is loaded through [Fontshare's official CSS API](https://www.fontshare.com/fonts/switzer). It is not bundled in this repository; when offline, the interface falls back to the system sans-serif font.

`FragmentMono-Regular.ttf` is bundled for labels and captions. It comes from [Google Fonts](https://fonts.google.com/specimen/Fragment+Mono) under the SIL Open Font License 1.1; see `OFL-FragmentMono.txt`.
